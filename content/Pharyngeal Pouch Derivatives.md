# Pharyngeal Pouch Derivatives

| Pouch | Derivative | Notes |
|---|---|---|
| 1st | Middle ear cavity, eustachian tube | |
| 2nd | Palatine tonsil (epithelial lining) | |
| 3rd | Ventral wing → thymus; dorsal wing → inferior parathyroid | 3rd pouch structures migrate further caudally than 4th, so the parathyroid it produces ends up inferior despite arising from the earlier pouch |
| 4th | Dorsal wing → superior parathyroid; ultimobranchial body → parafollicular (C) cells of thyroid | |

Mnemonic for the crossover: "3 goes low, 4 stays high" — 3rd pouch parathyroid ends up inferior, 4th pouch parathyroid ends up superior.

Failure of 3rd/4th pouch development is DiGeorge syndrome (22q11.2 deletion) — thymic aplasia (impaired T-cell maturation) plus parathyroid aplasia (hypocalcaemia). See [[Hypoparathyroidism]] and [[Primary Immunodeficiencies]].

Worth distinguishing the three pharyngeal structures by germ layer: pouches (endoderm, above), arches (mesoderm — cartilage, muscle, nerve, artery — see [[Aortic Arches]]), and clefts (ectoderm — only the 1st persists, forming the external auditory meatus; the rest are normally obliterated).
