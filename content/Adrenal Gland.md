# Adrenal Gland

Blood supply 
- Left and right suprarenal arteries
- Left adrenal vein -> renal vein -> IVC
- Right adrenal vein -> IVC

### Cortex

A. Composed of three layers that each secrete distinct hormones all made from cholesterol

Glomerulosa produces mineralocorticoids (e.g., aldosterone).
![[Pasted image 20241104103539.png|500]]
    
Fasciculata produces glucocorticoids (e.g., cortisol).
![[Pasted image 20241104103420.png|500]]
	
Reticularis produces sex steroids (e.g., testosterone).
![[Pasted image 20241104103615.png|500]]

Ketoconazole 
- Inhibits 17 alpha hydroxylase and desmolase
	- Blocks cortisol synthesis 
	- Can be used to treat Cushing's
- Inhibits 17,20 lyase
	- Decreased androstenedione/testosterone
	- Side effect - gynecomastia
### Medulla

Composed of neural crest-derived chromaffin cells. It is activated by ACh via nicotinic receptors
    
Main physiologic source of catecholamines (epinephrine and norepinephrine)
