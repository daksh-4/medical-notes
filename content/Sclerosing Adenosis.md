# Sclerosing Adenosis

|                                                                      |                                                                                                                                                                                                                                                                                                      |                                                       |
| -------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------- |
| Sclerosing adenosis, (radial scars and complex opsclerosing lesions) | - Usually presents as a breast lump or breast pain<br>- Causes mammographic changes which may mimic carcinoma<br>- Cause distortion of the distal lobular unit, without hyperplasia (complex lesions will show hyperplasia)<br>- Considered a disorder of involution, no increase in malignancy risk | Lesions should be biopsied, excision is not mandatory |
