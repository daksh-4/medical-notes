# Lipid-Lowering Drug Classes

| Class | Example | Mechanism | Main effect | Key downside |
|---|---|---|---|---|
| Statins | atorvastatin | HMG-CoA reductase inhibition → ↑LDL receptor expression | ↓↓LDL | myopathy, hepatotoxicity |
| Fibrates | fenofibrate | PPAR-α agonism → ↑LPL activity | ↓↓TG | myopathy (esp. with statins), gallstones — see Fibrates and gallstones |
| Ezetimibe | ezetimibe | Blocks NPC1L1 → ↓intestinal cholesterol absorption | modest ↓LDL | well tolerated, usually an add-on |
| Bile acid sequestrants | cholestyramine | Bind bile acids in gut → liver upregulates LDL receptors to make more | ↓LDL | GI upset, ↑TG, impairs fat-soluble vitamin absorption |
| PCSK9 inhibitors | evolocumab | Block PCSK9 → LDL receptors aren't degraded, recycle to hepatocyte surface | ↓↓↓LDL | injection site reactions, cost |
| Niacin | niacin | ↓hepatic VLDL secretion | ↑HDL (best), ↓TG | flushing (prostaglandin-mediated) |

Contrast with [[Familial dyslipidemias]], which covers the underlying lipoprotein disorders these drugs are used to treat.
