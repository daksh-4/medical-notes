# Orotic Aciduria: OTC Deficiency vs. UMP Synthase Deficiency

| | OTC deficiency | UMP synthase deficiency |
|---|---|---|
| Inheritance | X-linked recessive | Autosomal recessive |
| Defect | Urea cycle enzyme (ornithine transcarbamylase) — carbamoyl phosphate backs up into pyrimidine synthesis | De novo pyrimidine synthesis enzyme itself |
| Ammonia | High (urea cycle blocked) | Normal |
| Anaemia | None | Megaloblastic, doesn't respond to B12/folate |
| Treatment | Protein restriction, nitrogen scavengers | Uridine supplementation |

One-line rule: hyperammonaemia → think OTC deficiency; megaloblastic anaemia with normal ammonia → think UMP synthase deficiency.
