# Basal Ganglia

![[Pasted image 20241106141712.png|500]]

Striatum = Putamen + Caudate

- ﻿﻿Also called striate nucleus
- ﻿﻿Putamen/Caudate divided by internal capsule
- ﻿﻿Major INPUT from cortex
- ﻿﻿Lentiform Nucleus = Putamen + Globus Pallidus

Function
- Modifies voluntary movements
- Receives cortex input
- Provides feedback to cortex to either stimulate or inhibit

![[Pasted image 20241106141921.png|500]] complex movement

![[Pasted image 20241106142002.png|500]]

At rest GP externus and pars reticulata pour GABA on thalamus. 

![[Pasted image 20241106142149.png|500]]

Cortex releases glutamate onto striatum which pours GABA  on Globus pallidus internus and pars reticulata, this allows thalamus to stimulate the cortex and send impulses to brainstem and spinal cord. The pars compacta is also activated to release dopamine to amplify the whole process. 

Direct pathway
- Goal is to create movment
- Striatum inhibits GPi and Pars Reticulata
- GPi and Pars stop inhibiting Thalamus
- Thalamus is free to activate the cortex
- Modifier SN pars compacta modifies striatum via D1

![[Pasted image 20241106142323.png|500]] 

GP internus gets stimulated to extra inhibit the thalamus and cortex

Indirect pathway
- ﻿﻿Goal is to further inhibit movement
- ﻿﻿Striatum inhibits GPe (GABA)
- ﻿﻿GPe stops inhibiting Subthalamic nucleus
- ﻿﻿Subthalamic nucleus stimulates GPi
- ﻿﻿GPi further inhibits thalamus
- ﻿﻿Modifier: SN pars compacta modifies striatum via D2

The modifier process gets destroyed in Parkinson's
