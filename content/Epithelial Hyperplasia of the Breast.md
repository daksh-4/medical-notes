# Epithelial Hyperplasia of the Breast

|                        |                                                                                                                                                                                                                                                                                                                 |                                                                                                                               |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| Epithelial hyperplasia | - Variable clinical presentation ranging from generalised lumpiness through to discrete lump<br>- Disorder consists of increased cellularity of terminal lobular unit, atypical features may be present<br>- Atypical features and family history of breast cancer confers greatly increased risk of malignancy | If no atypical features then conservative, those with atypical features require either close monitoring or surgical resection |
